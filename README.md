# College Canteen Token System

A simple Python program for managing student food orders in a college canteen.

## Features

* View the canteen price list
* Place food orders for multiple students
* Enter student name and food item
* Enter the required quantity
* Calculate the total price based on quantity
* Generate a token number for each order
* Exit the canteen system

## Food Items and Prices

| Food Item  | Price |
| ---------- | ----: |
| Idli       |   ₹20 |
| Dosa       |   ₹40 |
| Fried Rice |   ₹80 |
| Juice      |   ₹30 |

## How It Works

1. The user selects an option from the college canteen menu.
2. The price list can be viewed.
3. When placing an order, the user enters the number of students placing orders.
4. For each student, the program takes:

   * Student name
   * Food item
   * Quantity
5. The program calculates the price based on the selected food item and quantity.
6. An order is displayed with the student's name, token number, quantity, and price.
